# Foto produk

Simpan foto asli sesuai nama berikut. Gambar ditampilkan utuh memakai `object-fit: contain`.

| File | Produk |
| --- | --- |
| gigabyte-graphic-card.png | Gigabyte Graphic Card (model belum dikonfirmasi) |
| quicksnap.png | Fujifilm QuickSnap Disposable Camera |
| instax-sq40.png | Instax SQ40 |
| instax-sq40-description.png | Infografis deskripsi dan fitur Instax SQ40 |
| instax-wide-400.png | Instax Wide 400 Black |
| instax-wide-400-green.png | Instax Wide 400 Green |
| instax-mini-pink-lemonade.png | Instax Mini Pink Lemonade, 10 sheets |
| instax-square-black-frame.png | Instax Square Black Frame, 10 sheets |
| instax-wide-twin-pack.png | Instax Wide Twin Pack, 20 sheets |

Delapan foto produk asli telah disalin dari lampiran yang diberikan pengguna, termasuk Gigabyte Graphic Card, Fujifilm QuickSnap, dan Instax Wide 400 Green. Infografis `instax-sq40-description.png` digunakan pada deskripsi SQ40. Banner horizontal baru disimpan sebagai `public/banners/instax-sq40.jpg` dan digunakan sebagai slide pertama Home. Konfigurasi slideshow berada di `src/lib/home-slides.ts`. Foto ditampilkan utuh; Next.js menyediakan ukuran responsif melalui image optimizer. Placeholder hanya muncul jika file gagal dimuat.

Logo asli dari lampiran juga telah disalin ke `public/brand/logo.png`. SVG sementara dipertahankan hanya sebagai fallback.
